% Appendix A: Source Code and Setup

\section{Source Code Repository}

The complete source code for the Hybrid Post-Quantum VPN is available on GitHub:

\begin{center}
\url{https://github.com/CubeStar1/hybrid-pqc-vpn}
\end{center}

The repository contains the full implementation, including the Python backend (hybrid cryptographic handshake, tunnel management, agent/gateway APIs) and the Electron + Next.js frontend dashboard.

\section{Prerequisites}

\begin{itemize}
    \item Linux (Ubuntu 22.04/24.04) -- required for TUN interface and UDP tunnel functionality
    \item Python 3.12+ and \texttt{uv} (\url{https://docs.astral.sh/uv/})
    \item Node.js 20+ and \texttt{pnpm}
    \item \texttt{liboqs} -- for ML-KEM-768 post-quantum support
\end{itemize}

\subsection{System Dependencies}

\begin{lstlisting}[language=bash, caption={Install System Dependencies}]
sudo apt update && sudo apt install -y \
  build-essential cmake ninja-build git curl \
  python3.12 python3.12-venv python3-pip \
  libssl-dev \
  libnss3 libatk-bridge2.0-0 libgtk-3-0 libgbm1 xdg-utils

curl -LsSf https://astral.sh/uv/install.sh | sh

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
npm install -g pnpm
\end{lstlisting}

\subsection{Building liboqs}

\begin{lstlisting}[language=bash, caption={Build and Install liboqs}]
cd /tmp
git clone --depth 1 https://github.com/open-quantum-safe/liboqs.git
cd liboqs && mkdir build && cd build
cmake -GNinja -DBUILD_SHARED_LIBS=ON -DCMAKE_INSTALL_PREFIX=/usr/local ..
ninja && sudo ninja install
sudo ldconfig
\end{lstlisting}

\section{Backend Setup}

The backend is a Python FastAPI application managed with \texttt{uv}.

\begin{lstlisting}[language=bash, caption={Install and Run the Backend}]
cd backend
cp .env.example .env
uv sync --all-extras

# Verify the hybrid crypto handshake
uv run python main.py demo-handshake

# Run the gateway API
uv run python main.py gateway-api

# Run the agent API
uv run python main.py agent-api
\end{lstlisting}

\subsection{Docker Deployment}

\begin{lstlisting}[language=bash, caption={Backend Docker Build and Run}]
cd backend
docker build -t hybrid-vpn-backend .

# Agent API
docker run --rm --env-file .env -p 8765:8765 hybrid-vpn-backend

# Gateway API
docker run --rm --env-file .env -p 9876:9876 hybrid-vpn-backend \
  python main.py gateway-api --host 0.0.0.0
\end{lstlisting}

Full TUN tunnel functionality requires elevated privileges:

\begin{lstlisting}[language=bash, caption={Docker Run with TUN Access}]
docker run --rm \
  --env-file .env \
  --cap-add=NET_ADMIN \
  --device /dev/net/tun \
  -p 8765:8765 \
  -p 4434:4434/udp \
  hybrid-vpn-backend
\end{lstlisting}

\section{Frontend Setup}

The frontend is a Next.js + Electron desktop dashboard, managed with \texttt{pnpm}.

\begin{lstlisting}[language=bash, caption={Install and Run the Frontend}]
cd frontend
pnpm install
cp .env.example .env

# Browser-only development (no Electron)
pnpm next:dev

# Full Electron + Next.js development mode
pnpm dev
\end{lstlisting}

# Health check
curl http://127.0.0.1:8765/health

# Agent status
curl http://127.0.0.1:8765/status | uv run python -m json.tool

# Demo handshake
curl -X POST http://127.0.0.1:8765/demo/handshake | uv run python -m json.tool

# Connect
curl -X POST http://127.0.0.1:8765/connect \
  -H "Content-Type: application/json" \
  -d '{"profile_id":"lab-gateway","username":"demo","password":"demo-vpn-2026"}'
\end{lstlisting}
