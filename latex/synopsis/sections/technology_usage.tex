\section{Technology Usage}
The project combines modern web technologies and cryptographic libraries. The backend uses Python for rapid prototyping and robust security, while the client features a modern Next.js and Tailwind CSS graphical user interface.

Major technologies include:
\vspace{0.2cm}

\begin{table}[h]
\centering
\begin{tabular}{|>{\bfseries}p{0.35\textwidth}|p{0.55\textwidth}|}
\hline
Category & Technologies \\
\hline
Frontend & Next.js, React, Tailwind CSS, TypeScript, Axios \\
\hline
Backend & Python, FastAPI, AsyncIO, Cryptography \\
\hline
Classical Cryptography & OpenSSL (X25519, ECDSA-P256, AES-GCM) \\
\hline
Post-Quantum Cryptography & liboqs (ML-KEM-768, ML-DSA) \\
\hline
Networking \& System & Linux TUN/TAP, Sockets \\
\hline
\end{tabular}
\end{table}

\vspace{0.2cm}
This stack offers a realistic platform for evaluating hybrid quantum-safe communications against conventional VPN setups.
